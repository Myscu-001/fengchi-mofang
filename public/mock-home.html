v3 改了什么

全部只作用于 App 端（安装态 / 触摸设备），网页桌面端完全不动

  1. 图标风格换成参考图那版新
    淡色圆角底（17px 圆角）+ 彩色细线图标，去掉了实色渐变和白色图标。7 个图标各一套色：蓝 / 红 / 紫 / 琥珀 / 绿 / 石板灰 / 青。
  2. 后 5 个管理页合并改动
    账号管理、角色权限、师资团队、站点配置、操作日志 → 收进一个「系统管理」文件夹图标，点开是从底部升起的抽屉，5 项带小图标和说明。普通老师登录时这个文件夹自动隐藏。
  3. 学习记录去掉改动
    它本来就是学员详情里的子页，不做独立入口。
  4. 首页内容清空改动
    统计卡、快捷入口、排行榜、公告全部移除，只剩图标区。
  5. 右上角公司 Logo改动
    56×56，和图标同尺寸同圆角（品牌红实色，Logo 保持实底更像品牌标识）。
  6. 底部栏固定不伸缩改动
    固定 60px 高、白底加顶部细线，滚动吸附底部；按下只变颜色不缩放，选中项下方加一条小短杠。Tab 也顺势改成 首页 / 学员 / 统计 / 我的。
